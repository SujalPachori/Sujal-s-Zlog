# ZLogs: Blog App with Admin Dashboard  

## Overview  
ZLogs is a robust blog management application designed using the MERN stack. It features a user-friendly interface for creating and managing blog content and an admin dashboard for overseeing posts, comments, and users. The app integrates modern technologies to deliver a seamless experience for both users and administrators.  

---

## Features  
### 1. Blog Management  
- Users can create, edit, and delete blog posts.  
- Integration with Firebase Storage for efficient management of profile images for over 300 users.  
- Dark Mode functionality to enhance user engagement.  

### 2. Admin Dashboard  
- Manage posts, comments, and users with ease.  
- View and moderate content with a streamlined interface.  

### 3. User Authentication  
- Secure user login and registration with JWT.  
- Role-based access control for administrators and regular users.  

### 4. Enhanced User Experience  
- Fully responsive design for optimal performance on all devices.  
- Seamless state management using Redux, reducing state-related bugs by 30%.  
- Improved data retrieval speed by 20% for faster content loading.  

---

## Tech Stack  
- **Frontend**: React.js, Tailwind CSS  
- **Backend**: Node.js, Express.js  
- **Database**: MongoDB  
- **State Management**: Redux  
- **Authentication**: JWT  
- **Cloud Storage**: Firebase
